# 组件总览

KKDUI 当前包含 40 个面向后台管理场景的组件。每个组件均提供在线示例、示例源码、常用 API 和完整 TypeScript 类型入口。

## 表单与筛选

- [Button 按钮](./button)：操作触发、加载、禁用、尺寸和危险操作。
- [Input 输入框](./input)：文本录入、密码显示、状态、尺寸和原生属性透传。
- [Textarea 文本域](./textarea)：多行文本、自动高度和字数限制。
- [NumberInput 数字输入](./number-input)：步进、边界和精度控制。
- [RadioGroup 单选组](./radio-group)：带说明的互斥选项。
- [SegmentedControl 分段控制](./segmented-control)：少量模式紧凑切换。
- [Select 选择器](./select)：固定选项普通单选。
- [Combobox 组合框](./combobox)：本地或远程搜索单选。
- [MultiSelect 多选器](./multi-select)：可搜索的多值筛选。
- [TagInput 标签输入](./tag-input)：标签录入、批量粘贴与校验。
- [DateRangePicker 日期范围](./date-range-picker)：日期范围和统计粒度。
- [Checkbox 复选框](./checkbox)：布尔、批量与半选状态。
- [Switch 开关](./switch)：立即生效的状态切换。
- [FormItem 表单项](./form-item)：标签、帮助与错误反馈。
- [FormSection 表单分区](./form-section)：复杂表单结构化分组。
